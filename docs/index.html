Data & setup Everything is stored only in this browser — nothing is ever uploaded anywhere (except optional poster lookups to TMDB).

1. Sync your Letterboxd export

Export from Letterboxd → Settings → Data, unzip it, and pick diary.csv and/or ratings.csv below. Re-sync any time to add new movies or update ratings/watched dates — it upserts by title+year, so it's safe to run repeatedly.

2. Move to another device, or just back up

This browser is the only copy of your data. Export a backup file, then import it on another device (or after clearing browser data) to pick up exactly where you left off.

Migrating comparisons from the local server app?

Generate a comparisons export there (see the README's "Migrating to the static version" section), sync your CSV above first, then import it here. Safe to run more than once -- it only fills in pairs that don't already have a comparison recorded.

Posters (optional)

Paste your own free TMDB API key to show posters instead of plain title cards. Stored only in this browser, sent only to TMDB, never anywhere else.
